# 변경 이력 — 2026-05-12

## 현재 시스템 구조 (이 날 기준 최종 상태)

```
PDF 업로드 → 텍스트 추출 (PDFBox)
         → 청크 분할 (문단 경계 기준, 최대 2500자)
         → 각 청크 병렬 번역 (언어별 모델 라우팅)
         → 번역본 합치기
         → 번역본 앞 6000자로 한국어 요약
         → DB 저장
```

- 번역 후 요약 구조 (원문 직접 요약 아님)
- 상세 페이지: 요약 + 번역 전문 표시
- 언어별 모델 라우팅: EN → EXAONE 3.5 32B AWQ (포트 8001), ZH/JA → Qwen 2.5 14B (포트 8000)

## 작업 이력

### [아키텍처] 번역 후 요약 구조 복원
- **이유**: 번역 단계를 제거하는 방향으로 진행했으나, project_context.md에 명시된 원래 설계(번역 → 합치기 → 요약)로 복원
- **최종 흐름**: 청크 병렬 번역 → translatedText 합산 → translatedText.take(6000) 요약
- **변경 파일**:
  - `PdfService.kt` — Flux.flatMapSequential 병렬 번역 + 타이밍 로그 복원
  - `PdfSummaryResponse.kt` — `originalText` 필드 → `translatedText` 필드 복원
  - `PdfExportService.kt` — `doc.originalText` → `doc.translatedText`, "원문 전문" → "번역 전문"
  - `detail.html` — "원문 전문" 탭 → "번역 전문" 탭, `doc.translatedText` 표시

### [아키텍처] 언어별 멀티 모델 라우팅
- **이유**: Qwen 모델은 중국어 편향이 강해 EN 번역 품질이 불안정. EXAONE 3.5 32B AWQ는 한국어/영어 특화로 EN 번역 품질 기대.
- **신규 파일**:
  - `config/VllmProperties.kt` — `@ConfigurationProperties(prefix = "vllm")`, 언어별 (baseUrl, model) 쌍 보관
- **변경 파일**:
  - `VllmService.kt` — `VllmProperties.resolve(lang)` → 언어에 맞는 vLLM 서버/모델 선택. `ConcurrentHashMap<String, WebClient>` 캐시로 WebClient 재사용.
  - `WebClientConfig.kt` — `@Bean vllmWebClient` 제거, `buildWebClient(baseUrl)` 팩토리 메서드로 변경
  - `PdfSummaryApplication.kt` — `@ConfigurationPropertiesScan` 추가 (VllmProperties 등록)
  - `application.yaml` — `vllm.language-models: {}` 빈 맵 기본값 추가
  - `application-local.yaml` — EN/ZH/JA 각 언어별 base-url + model 설정

### [품질] 번역 품질 개선 — CJK 재시도 로직
- **이유**: 번역 결과에 중국어 문자(CJK 0x4E00~0x9FFF)가 15자 이상 포함되면 품질 불량 판단
- **변경 파일**: `VllmService.kt` — `callTranslate()` 결과에서 CJK 카운트 확인, 초과 시 retry=true 재호출 (간소화된 프롬프트)

### [품질] 표/그림 번역 처리
- **이유**: PDFBox로 추출한 표 구조를 가능한 한 보존, 그림 캡션 포맷 유지
- **변경 파일**: `VllmService.kt` — 번역 프롬프트에 표 마크다운(| 파이프) 보존 및 "그림 N." 포맷 지시 추가

### [버그] 청크 분할 — 2500자 초과 단락 처리 누락
- **이유**: 단일 단락이 maxChunkSize(2500자) 초과 시 `.take(maxChunkSize)`로 잘라내 나머지를 버리고 있었음
- **변경 파일**: `PdfParserService.kt` — 초과 단락을 while 루프로 maxChunkSize씩 분할해 여러 청크로 나눔

### [버그] 타이밍 로그 누락
- **이유**: 번역 단계 제거 작업 중 청크별 타이밍 로그가 함께 삭제됨
- **변경 파일**: `PdfService.kt` — 추출/청크수/번역 소요/요약 소요/전체 소요 로그 복원

### [버그] PDF 업로드 크기 제한
- **이유**: Spring Boot 기본 multipart 제한 1MB로 인해 일반 학술 PDF에서 413 에러 발생
- **변경 파일**: `application.yaml` — `max-file-size: 100MB`, `max-request-size: 110MB` 추가

### [인프라] DB 마이그레이션: 로컬 MariaDB → DGX Spark PostgreSQL
- **변경 파일**:
  - `application.yaml` — PostgreSQL 드라이버/dialect
  - `application-local.yaml` — DGX Spark PostgreSQL 접속 정보
  - `schema.sql` — BIGSERIAL, TEXT, ADD COLUMN IF NOT EXISTS
  - `PdfDocument.kt` — `columnDefinition = "TEXT"`
  - `build.gradle.kts` — mariadb-java-client → postgresql 드라이버

### [인프라] EXAONE 3.5 32B AWQ 컨테이너 설정
- **이유**: BF16 32B 모델 (~64GB) 다운로드 중 장시간 대기 후 AWQ 버전으로 전환 결정
- **모델**: `LGAI-EXAONE/EXAONE-3.5-32B-Instruct-AWQ` (공식 배포, HuggingFace)
- **포트**: 8001 (Qwen 14B는 8000 유지)
- **알려진 이슈**: `vllm-exaone.sh`의 `--model` 라인에 `\` 뒤 공백이 있어 "unrecognized arguments:" 에러. 서버에서 해당 라인 공백 제거 필요.

### [설정] config 파일 보안 규칙 정립
- `application-local.yaml.example` — git 커밋용, 플레이스홀더만. PostgreSQL URL 형식으로 수정.
- `application-local.yaml` — gitignore. 실제 접속 정보.
- `CLAUDE.md` — 체인지로그 규칙 및 config 파일 규칙 추가
