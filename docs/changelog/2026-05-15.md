# 변경 이력 — 2026-05-15

## 현재 시스템 구조

```
[동기 — HTTP 요청 내]
POST /upload (file, sourceLang, processMode)
  → SHA-256 해시 중복 체크 (비관적 락, FOR UPDATE)
      중복이면 → CACHED 즉시 반환
  → PDFBox 텍스트 추출 (~1-2초)
  → DB 저장 (status=PROCESSING, processMode 저장)
  → 즉시 반환 (HTTP 응답 종료)

[비동기 — pdfTaskExecutor (core=2, max=4)]
  processMode에 따라 분기:

  TRANSLATE:
    → 청크 분할 (최대 2500자, 300자 오버랩)
    → 병렬 번역 (concurrency=10)
       EN → EXAONE 3.5 32B AWQ / ZH·JA → Qwen 2.5 14B
    → DB 업데이트 (status=DONE, translatedText)

  SUMMARIZE:
    → 청크 분할 (5000자, 오버랩 없음)
    → 원문 직접 소요약 병렬 생성 (summarizeFromSourceAsync, concurrency=4)
       각 언어별 모델 라우팅 적용
    → 소요약 합산 (최대 4000자) → 최종 요약 (Qwen 14B, maxTokens=1500)
    → DB 업데이트 (status=DONE, summary)

  BOTH:
    → TRANSLATE 단계 수행
    → 번역본을 5000자 청크로 분할 → 소요약 병렬 생성 (concurrency=4)
    → 소요약 합산 → 최종 요약
    → DB 업데이트 (status=DONE, translatedText, summary)

[안전장치]
  → @Scheduled (1분마다): PROCESSING 상태가 30분 초과 시 FAILED 자동 전환
  → UI: PROCESSING 문서 존재 시 5초마다 자동 새로고침
  → FAILED 문서: UI에서 원클릭 재시도 가능
```

## 인프라

- vLLM Qwen 2.5 14B: DGX Spark GB10 (:8000)
- PostgreSQL: 로컬 Docker

## 작업 이력

### [기능] ProcessMode 3버튼 선택 기능 구현
- **이유**: 사용자마다 번역만 필요하거나 요약만 필요한 경우가 다름. 단일 [번역/요약] 버튼에서 [번역] / [요약] / [번역/요약] 3개 버튼으로 분리
- **변경 파일**:
  - `domain/ProcessMode.kt` (신규) — TRANSLATE / SUMMARIZE / BOTH enum
  - `domain/PdfDocument.kt` — processMode 필드 추가 (기본값 BOTH)
  - `resources/schema.sql` — process_mode 컬럼 추가
  - `service/VllmService.kt` — `summarizeFromSourceAsync()` 추가 (원문 언어 직접 소요약)
  - `service/PdfAsyncProcessor.kt` — processMode 분기 리팩토링 (doTranslate / doSummarize / doTranslateAndSummarize)
  - `service/PdfService.kt` — upload()에 processMode 파라미터 추가
  - `controller/PdfController.kt` — processMode 파라미터 수용
  - `controller/PageController.kt` — processMode 파라미터 수용, 처리 모드별 flash 메시지
  - `dto/PdfUploadResponse.kt` — processMode 필드 추가
  - `dto/PdfSummaryResponse.kt` — processMode 필드 추가
  - `templates/index.html` — 3버튼 UI, 소요시간 안내 문구, 버튼별 색상 구분
  - `templates/detail.html` — processMode 기반 조건부 렌더링 (요약/번역 섹션), 다운로드 버튼 translatedText 존재 시에만 표시
- **결과**: processMode별 최적 처리 경로 실행. [요약] 모드는 번역 없이 원문 직접 소요약 → 빠른 처리 가능
