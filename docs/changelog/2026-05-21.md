# 변경 이력 — 2026-05-21

## 현재 시스템 구조

```
[동기 — HTTP 요청 내]
POST /upload (file, sourceLang, processMode)
  → SHA-256 해시 + processMode별 중복 체크 (비관적 락)
      이미 같은 결과 있으면 → CACHED → /detail/{id} 리다이렉트
  → PDFBox 텍스트 추출
  → DB 저장 (status=PROCESSING, processMode, llmProvider 저장)
  → 즉시 반환

[비동기 — pdfTaskExecutor]
  → doc.llmProvider에 따라 LLM 서비스 선택:
      LOCAL  → VllmService (기존 EXAONE/Qwen)
      CLAUDE → ClaudeService (Anthropic API)
      GEMINI → GeminiService (Google API)
  → processMode에 따라 번역/요약/번역+요약 수행
  → DB 업데이트 (status=DONE, translatedText, summary, llmProvider)

[학습 데이터 수집]
  → external-llm.provider=CLAUDE 또는 GEMINI 설정
  → 처리된 문서가 llm_provider=CLAUDE/GEMINI 로 DB에 저장
  → GET /api/pdf/training/export → JSON 배열 반환
  → GB10 파인튜닝 스크립트가 이 데이터로 LoRA 학습

[안전장치]
  → @Scheduled (1분마다): PROCESSING 30분 초과 시 FAILED 자동 전환
  → UI: PROCESSING 문서 5초마다 자동 새로고침
  → FAILED: 원클릭 재시도 가능
```

| Spring Boot 앱 | 로컬 PC (Docker, :8880) | 웹 서버 |

## 작업 이력

### [아키텍처] Claude/Gemini API 연동 + LoRA 파인튜닝 학습 데이터 파이프라인 구축

**이유**: GB10 로컬 모델(EXAONE/Qwen)을 LoRA로 파인튜닝하여 품질을 점진적으로 개선하는 파이프라인 구축.
Claude/Gemini가 고품질 "선생(Teacher)" 출력을 생성하면 이를 DB에 저장 후 GB10에서 LoRA 학습에 활용.

**변경 파일**:

**신규 생성 (5개 파일):**
- `domain/LlmProvider.kt` — enum: LOCAL / CLAUDE / GEMINI (displayName 포함)
- `service/LlmService.kt` — 번역·요약 공통 인터페이스. VllmService, ClaudeService, GeminiService가 구현
- `config/ExternalLlmProperties.kt` — `external-llm.*` 설정 프로퍼티 (provider, API 키, 모델명)
- `service/ClaudeService.kt` — Anthropic Claude API 번역·요약 구현 (`https://api.anthropic.com/v1/messages`)
- `service/GeminiService.kt` — Google Gemini API 번역·요약 구현 (`/v1beta/models/{model}:generateContent`)
- `dto/TrainingRecord.kt` — LoRA 파인튜닝용 Alpaca 형식 학습 데이터 레코드 DTO

**기존 수정 (8개 파일):**
- `domain/PdfDocument.kt` — `llmProvider: LlmProvider` 필드 추가 (val, 기본값 LOCAL)
- `schema.sql` — `llm_provider VARCHAR(20) NOT NULL DEFAULT 'LOCAL'` 컬럼 추가
- `service/VllmService.kt` — `LlmService` 인터페이스 구현 선언 추가
- `service/PdfAsyncProcessor.kt` — ClaudeService/GeminiService 주입 + `llmFor(provider)` 라우팅 메서드 추가, 모든 private 메서드에 `LlmService` 파라미터 전달
- `service/PdfService.kt` — ExternalLlmProperties 주입, newDoc 생성 시 `llmProvider` 설정, `exportTrainingData()` 메서드 추가
- `repository/PdfDocumentRepository.kt` — `findByStatusAndLlmProviderNot()` 파생 쿼리 추가
- `dto/PdfSummaryResponse.kt` — `llmProvider` 필드 추가
- `controller/PdfController.kt` — `GET /api/pdf/training/export` 엔드포인트 추가
- `resources/application.yaml` — `external-llm.*` 기본값 섹션 추가
- `resources/application-local.yaml.example` — API 키 플레이스홀더 추가

**결과**:
- `application-local.yaml`에서 `external-llm.provider: CLAUDE`로 변경하면 즉시 Claude API 사용
- 처리된 모든 문서에 `llm_provider` 기록 → 어느 모델이 생성했는지 추적 가능
- `GET /api/pdf/training/export` → Claude/Gemini 생성 결과를 JSON 배열로 반환 (파인튜닝 데이터)

## 학습 데이터 파이프라인 전체 흐름

```
1. application-local.yaml 변경:
     external-llm:
       provider: CLAUDE          # 또는 GEMINI
       claude:
         api-key: sk-ant-xxx

2. PDF 업로드 → Claude API가 번역/요약 → DB에 llm_provider=CLAUDE로 저장

3. 학습 데이터 export (GB10에서 실행):
     curl http://localhost:8880/api/pdf/training/export > training.json
     # JSONL 변환이 필요하면:
     cat training.json | jq -c '.[]' > training.jsonl

4. GB10에서 LoRA 파인튜닝 (Python 스크립트 별도 작성 필요):
     python train.py --data training.jsonl --model EXAONE-3.5-32B --output ./lora-weights

5. 파인튜닝 완료 후 vLLM 재시작 (LoRA 어댑터 적용):
     docker restart vllm-exaone
```

## GB10에서 해야 할 작업 (Spring Boot 외부)

### 1. vLLM VRAM 제한 (방안 2 — 즉시 적용 가능)
`docker-compose.yml` 또는 vLLM 시작 명령어에 추가:
```bash
--gpu-memory-utilization 0.4   # VRAM 40%만 사용 → 나머지 60%를 파인튜닝에 할당
```
> EXAONE 32B AWQ 기준 40%면 약 38-50GB. 파인튜닝에 나머지 50-60GB 사용 가능.

### 2. LoRA 파인튜닝 Python 스크립트 작성
```python

# pip install unsloth trl

from unsloth import FastLanguageModel
from trl import SFTTrainer
import json

# training.jsonl 읽어 Alpaca 형식으로 학습
```

### 3. 시간차 스케줄링 (방안 1 — 선택 사항)
새벽 2시에 vLLM 컨테이너를 자동 중지하고 파인튜닝 후 재시작.
Spring Boot 스케줄러에서 `docker stop / docker start` 명령 실행 가능 (Docker socket 마운트 필요).

### 4. 파인튜닝 완료 후 모델 교체
```bash
# vLLM에 LoRA 어댑터 적용하여 재시작
docker run ... vllm serve EXAONE-3.5-32B \
  --enable-lora \
  --lora-modules my-adapter=/path/to/lora-weights
```
