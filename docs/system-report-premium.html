💡 앗, 이 용어가 낯선가요?

시스템 설계에 사용된 전문 용어들을 알기 쉽게 풀어드립니다.

LoRA (Low-Rank Adaptation)
초거대 AI를 처음부터 다시 학습시키는 건 너무 비싸고 오래 걸립니다. 대신 AI의 원래 '뇌'는 놔두고, 아주 얇은 '요약 노트(가중치)'만 덧붙여서 빠르고 저렴하게 특정 분야(예: 번역)의 천재로 만드는 최신 AI 과외 기법입니다.
Map-Reduce (맵-리듀스) 요약
두꺼운 책을 한 명이 다 읽으려면 너무 오래 걸리죠? 책을 여러 장으로 쪼개서 여러 명에게 동시에 요약하게 시킨 뒤(Map), 그 요약본들을 다시 리더가 모아서 최종본으로 합치는(Reduce) 초고속 분산 처리 방식입니다.
vLLM
사내 서버에서 거대한 AI 모델을 직접 돌릴 때, AI가 대답을 생성하는 속도를 획기적으로 끌어올려 주는 '초고속 AI 엔진'입니다. 메모리를 엄청나게 효율적으로 아껴줍니다.
Fallback (자동 우회/전환)
주력으로 쓰는 외부망(예: Gemini)이 터지거나 무료 할당량을 다 썼을 때, 사용자 모르게 즉시 사내망(LOCAL AI)으로 스위치를 돌려 서비스가 절대 멈추지 않게 방어하는 기술입니다.
비관적 락 (Pessimistic Lock)
"이 파일은 내가 지금 작업 중이니 아무도 건드리지 마!" 하고 DB에 단단히 자물쇠를 걸어버리는 기술입니다. 여러 사람이 동시에 같은 파일을 업로드해도 시스템이 꼬이지 않게 완벽히 차단합니다.
