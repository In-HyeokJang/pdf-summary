학습 데이터 내보내기
DONE 상태 + llm_provider≠LOCAL 인 레코드를 Alpaca 형식 JSON으로 반환
curl http://localhost:8880/api/pdf/training/export > training.json
cat training.json | jq -c '.[]' > training.jsonl
3
GB10에서 LoRA 파인튜닝
Unsloth / HuggingFace TRL로 EXAONE 3.5 32B / Qwen 2.5 14B 파인튜닝

API 명세

POST /api/pdf/upload PDF 업로드 및 처리 시작 file, sourceLang, processMode, translatePrompt?, summaryPrompt?
GET /api/pdf/list 전체 문서 목록 조회 —
GET /api/pdf/{id} 문서 상세 조회 id
POST /api/pdf/retry/{id} FAILED 문서 재처리 id
GET /api/pdf/training/export LoRA 학습 데이터 내보내기 Alpaca 형식 JSON 배열
GET /download/{id} 번역본 PDF 다운로드 id
문서 처리 상태 흐름
PENDING
업로드 직후 초기 상태
PROCESSING
LLM 처리 중 (5초 폴링)
DONE
처리 완료, 조회 가능
FAILED
오류 발생, 재시도 가능
CACHED
동일 파일 중복 업로드
