# DGX Spark (GB10) 로컬 LLM 추론 및 자율 학습 최적화 방안
**문서 목적:** 안티그래비티(Anti-Gravity) 팀 협의 및 기존 개발 로직 수정 요청용

## 1. 현재 직면한 문제점 (As-Is)
* **환경:** NVIDIA DGX Spark (GB10), Spring Boot, PostgreSQL, Docker (EXAONE / Qwen 모델 서빙)
* **현상:** 추론(번역/요약) 컨테이너가 구동 중일 때 GPU 메모리(VRAM)가 거의 가득 차며 전반적인 속도 저하 발생.
* **문제:** 이 상태에서 모델 성능 향상을 위한 자체 학습(Fine-Tuning) 스크립트를 동시에 실행할 경우, 메모리 부족(OOM: Out Of Memory) 에러가 발생하여 자율 학습 파이프라인 구축이 불가함.

## 2. 원인 분석
* 일반적인 LLM 고속 추론 엔진(예: vLLM 등)은 빠른 응답 속도를 위해 구동 시 가용한 GPU 메모리의 대부분(기본 90% 이상)을 KV Cache용으로 사전 할당(선점)합니다.
* 따라서 물리적인 메모리(GB10의 통합 HBM 96~128GB)가 충분하더라도, 추론 엔진이 자원을 독점하고 있어 남은 여유 공간에 학습 프로세스가 올라갈 자리가 없습니다.

## 3. 해결 및 최적화 방안 (To-Be)
단일 GB10 장비 환경에서 '추론(서비스)'과 '학습(파인튜닝)'을 모두 소화하기 위해 다음 3가지 전략 중 하나(또는 복합)를 적용하여 기존 로직을 수정하고자 합니다.

### 방안 1: 시간차 스케줄링 (스왑 방식) - 가장 안정적
* **개요:** 추론과 학습을 동시에 돌리지 않고 시스템 사용 시간을 분리합니다.
* **수정 요청 사항:**
    * Spring Boot 스케줄러를 통해 트래픽이 적은 시간(예: 새벽 2시)에 현재 구동 중인 추론 컨테이너(Docker)를 일시 중지(Stop)합니다.
    * 확보된 전체 VRAM을 활용하여 파이썬 학습 컨테이너를 구동, 축적된 DB 데이터를 바탕으로 LoRA 파인튜닝을 진행합니다.
    * 학습 완료 후 학습 컨테이너를 종료하고, 업데이트된 새 가중치로 추론 컨테이너를 재시작하는 백엔드(Java) 로직 구현이 필요합니다.

### 방안 2: 추론 엔진 VRAM 강제 제한 (동시 구동 방식)
* **개요:** 추론 엔진이 VRAM을 100% 독점하지 못하게 제한하여, 백그라운드 학습용 여유 메모리를 상시 확보합니다.
* **수정 요청 사항:**
    * 추론 서빙용 Docker Run 명령어 또는 `docker-compose.yml` 설정 변경.
    * (vLLM 사용 시) `--gpu-memory-utilization 0.4` (또는 0.5) 옵션을 추가하여 추론 엔진이 VRAM의 40~50%만 사용하도록 강제 제한.
    * 남은 절반의 VRAM 공간에서 백그라운드 모델 학습이 안전하게 돌아갈 수 있는지 테스트 및 반영.

### 방안 3: 모델 양자화(Quantization) 및 LoRA 필수 적용
* **개요:** 절대적인 메모리 사용량 자체를 대폭 줄여 여유 공간을 만듭니다.
* **수정 요청 사항:**
    * 현재 사용 중인 EXAONE / Qwen 모델이 원본(16bit)인지 확인 후, **4bit 또는 8bit 양자화(AWQ, GPTQ 등) 모델로 교체**. (7B 모델 기준 메모리 점유율을 15GB 수준에서 5~6GB 수준으로 대폭 절감 가능)
    * 학습 스크립트 작성 시 전체 가중치 학습(Full Fine-tuning)이 아닌 **PEFT/LoRA** 기법이 반드시 적용되도록 파이썬 코드 리뷰 및 수정.

## 4. 안티그래비티 팀 검토 요청 사항 (Action Items)
1. **[인프라/옵션]** 현재 도커로 띄워진 추론 엔진의 시작 명령어(옵션) 확인 및 VRAM 할당량 튜닝(제한) 가능 여부 검토
2. **[백엔드]** Spring Boot에서 로컬 Docker 컨테이너를 Stop/Start로 제어하고 모니터링하는 스케줄러 로직 추가 공수 산정
3. **[AI/모델]** 현재 적용된 모델의 양자화 여부 파악 및 파인튜닝 시 LoRA 적용 상태 점검
